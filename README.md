# RSA_sample

このリポジトリは、RSA暗号をはじめとする公開鍵暗号の仕組みや実装サンプルをまとめたプロジェクトです。

## 概要

公開鍵暗号（RSAなど）は、現代のインターネットにおけるセキュアな通信の根幹を支える技術です。当リポジトリでは、その数学的な背景やアルゴリズムの挙動をシンプルなコードと解説を通じて理解することを目指しています。

より詳細な数学的解説や理論的な背景については、以下の外部ノートもあわせてご覧ください：
- [暗号についての詳しい解説（doublePoint.md）](https://github.com/yabusan2-dot/technical-essays-notes/blob/main/doublePoint.md)

## 特徴

- **分かりやすい実装:** 暗号アルゴリズムの仕組みを直感的に把握できるシンプルなコード。
- **基礎からのアプローチ:** 鍵生成、暗号化、復号化の流れを順に追える構成。

## 使い方・ファイル構成

- `README.md`: 本ドキュメント
- サーバー⇒クライアントの順に起動して、クライアントで通信文を入力してください。
